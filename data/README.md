# Домашнее задание: Классификация налоговых форм в PDF документах

## Описание задачи

Перед вами стоит задача классификации налоговых документов. Необходимо взять исходные PDF файлы с налоговыми декларациями (Tax Return) и определить, какие конкретные налоговые формы находятся на каких страницах документа.

### Входные данные
- **Папка `data/input/`**: содержит 10 PDF файлов (`dummy1.pdf` - `dummy10.pdf`) с налоговыми документами
- Каждый PDF может содержать несколько различных налоговых форм (например, Form 1040, Schedule A, Schedule B, Form 8863 и т.д.)
- Формы могут занимать одну или несколько страниц

### Выходные данные (эталон)
- **Папка `data/target/`**: содержит эталонную разметку в формате JSON для каждого PDF файла
- Формат JSON файла:
```json
{
  "forms": [
    {
      "document_type": "1040f",
      "start_page": 1,
      "end_page": 2
    },
    {
      "document_type": "f1040sa",
      "start_page": 3,
      "end_page": 4
    }
  ]
}
```

### Список возможных типов документов
Основные федеральные налоговые формы США:
- `1040f` - Form 1040 (основная налоговая декларация)
- `f1040sa` - Schedule A (детализированные вычеты)
- `f1040sb` - Schedule B (проценты и дивиденды)
- `f1040sc` - Schedule C (доход от бизнеса)
- `f1040sd` - Schedule D (прирост/убыток капитала)
- `f1040se` - Schedule E (доход от аренды и партнерств)
- `f1040s1` - Schedule 1 (дополнительный доход)
- `f1040s2` - Schedule 2 (дополнительные налоги)
- `f1040s3` - Schedule 3 (дополнительные кредиты)
- `f8863` - Form 8863 (образовательные кредиты)
- `f8812` - Form 8812 (детский налоговый кредит)
- `f2441` - Form 2441 (расходы на уход за детьми)
